אודות המודל

K-Means משייך כל נקודה לצנטרואיד הקרוב אליה, ולאחר מכן מזיז כל צנטרואיד לממוצע הנקודות המשויכות אליו. חזרה על התהליך מובילה להתכנסות. נסו לגרור צנטרואיד ידנית ולבחון כיצד השיוך משתנה, או הפעילו נרמול Min-Max כדי לראות כיצד חריגים משפיעים על החלוקה.

תרחישים חדשים תמיד נשמרים בדפדפן הזה. אם תגדירו כאן טוקן GitHub עם הרשאת כתיבה לריפו, כל תרחיש חדש גם ייכתב אוטומטית ל-catalog.json בענף main — ויופיע לתלמידים תוך כדקה, בלי שום פעולה ידנית נוספת.

יצירת תרחיש חדש

התרחיש נשמר אוטומטית בדפדפן הזה ויישאר גם אחרי רענון או סגירה. אם הגדרתם טוקן GitHub למעלה, הוא גם יסונכרן אוטומטית ל-catalog.json ויופיע לתלמידים. בלי טוקן, השמירה מקומית בלבד — ייצאו קונפיגורציה (למטה) או העתיקו ידנית ל-catalog.json כדי לפרסם.
